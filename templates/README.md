# Templates

This folder is intentionally empty for now.

It will hold starter project skeletons (e.g. a Next.js starter, a static
site starter) that a new project can be copied from — but only once a
given setup has actually been used and proven on a real project. Don't
add a speculative starter here; build the real project first, then
generalize it back into a template if it's likely to be reused as-is.
